1. Executive Concept & The Two-Tier Gateway Model

Inspired by the West Bengal Social Security (BMSSY) and WB e-Paddy architectures, KishanQueue decouples operations into two specialized interfaces sharing a real-time event pipeline:

Portal GatewayTarget PersonaAuthenticationCore Capabilities
Door 1: Citizen / Farmer Portal Farmers, tractor drivers, rural producers Mobile OTP, Krishak Bandhu ID, KCC Voice-driven pass creation, radial queue radar, slot booking, transit delay buffer, offline QR ticket.
Door 2: Operator / Official Desk Gate guards, scale operators, assayers, secretary Official Mandi ID + PIN / MFA Weighbridge serial telemetry, FAQ quality deductions, DBT voucher compilation, statutory APMC ledger exports.

3. Voice-First AI & Regional Language Intelligence

Overcoming the Digital Literacy Divide: Most rural farmers face literacy barriers. KishanQueue introduces a zero-reading voice assistant supporting Bengali, Hindi, and English via the Web Speech API and Bhashini models. Farmers speak naturally (e.g., "৫০ কুইন্টাল ধান বিক্রির পাস দিন") to automatically book tickets, check wait times, and receive audio updates.

4. The 52 Consecutive Master Specifications

Section A: Citizen & Illiterate Farmer Accessibility (Points 01–14)

  1. Point 01: Multi-Identity Verification Module — Support for Krishak Bandhu ID, Kisan Credit Card (KCC), and Mobile OTP.
  2. Point 02: Pre-Arrival Slot Scheduler — Appointment booking dividing the day into calibrated 2-hour weighbridge capacity bands.
  3. Point 03: Live Dynamic Radial Turn Indicator — Visual radar showing real-time queue position and dynamic wait times.
  4. Point 04: Native Web Speech Audio Engine — Spoken announcements in Bengali, Hindi, and English (e.g., "টোকেন ১০৮, স্কেল ২ এ আসুন").
  5. Point 05: Offline Cryptographic Pass — Client-side HMAC-SHA256 QR code passes saved in browser localStorage for offline verification.
  6. Point 06: SMS / WhatsApp Cloud Push Gateway — Automated alerts dispatched when the farmer is 3 slots away from the gate.
  7. Point 07: Perishable Produce Priority Routing — Express lane routing for perishable crops (tomatoes, greens) over dry cereals.
  8. Point 08: Farmer Transport Breakdown Hold Toggle — "Report Transit Delay" button providing a 45-minute grace period.
  9. Point 09: Live Minimum Support Price (MSP) Ticker — Real-time daily APMC market price feeds from data.gov.in APIs.
  10. Point 10: Multi-Tractor / Multi-Lot Registration — Single farmer account registering multiple haulage vehicles under linked sub-tokens.
  11. Point 11: Mandi Approach Road Congestion Monitor — Live road status indicators showing approach traffic and yard capacity.
  12. Point 12: Digital Grievance Redressal / Dispute Log — In-app button to dispute tare weights or moisture cuts with APMC arbiters.
  13. Point 13: Universal Visual Iconography — High-contrast pictorial icons allowing fully non-literate farmers to navigate easily.
  14. Point 14: Interactive Voice Response (IVR) Fallback — Toll-free telephone missed-call registration for basic keypad feature phones.

Section B: Operator & Mandi Administration Desk (Points 15–26)

  1. Point 15: Granular Role-Based Access Control (RBAC) — Discrete portal views for Guards, Scale Operators, Assayers, and Mandi Secretary.
  2. Point 16: IoT Hardware Weighbridge Bridge — Direct serial telemetry capturing gross/tare weights from Avery and Essae indicators.
  3. Point 17: Two-Stage Tare & Gross Math Engine — Automated net calculation (Net = Gross - Tare - BagTare) with vehicle payload checks.
  4. Point 18: Gunny Bag Standardization Table — Preset tare deductions for packaging types (Jute 50kg = 580g; HDPE plastic = 120g).
  5. Point 19: ICAR Fair Average Quality (FAQ) Evaluator — Standardized deduction computation for moisture, foreign matter, and broken grains.
  6. Point 20: Operator Absent / No-Show Handling — Ability to place absent tokens on "Standby Hold", recalling them after two turns.
  7. Point 21: High-Contrast Big-Screen Public Display Mode — Dedicated `/display` full-screen page for yard LED signboards.
  8. Point 22: Counter Reassignment & Load Balancing — Dynamic re-routing of queues if an active weighbridge scale breaks down.
  9. Point 23: Hamali & Unloading Labor Allocation — Gang assignment and tracking for registered mandi laborers.
  10. Point 24: End-of-Day APMC Ledger Generation — One-click statutory accounting ledger export matching Agricultural Marketing Board standards.
  11. Point 25: Tamper-Evident Audit Logging — Immutable log recording all manual weight overrides, cancellations, and staff actions.
  12. Point 26: Mill / Warehouse Dispatch Integration — Automated outward delivery Challan generation routing accepted grain to FCI warehouses.

Section C: Procurement Valuation & Financial Settlement (Points 27–36)

  1. Point 27: Automated MSP Price Multiplier — Lot valuation multiplying certified net quintals by active government support rates.
  2. Point 28: Statutory APMC Fee & Cess Ledger — Clear itemization of market fees, weighing cess, and farmer subsidies.
  3. Point 29: Hamali Subsidy Reconciliation — Transparent documentation of government unloading subsidies credited back to the farmer.
  4. Point 30: Direct Benefit Transfer (DBT) Integration — Payment payload compilation for PFMS and NPCI Aadhaar Payment Bridge.
  5. Point 31: Electronic Weighment & Pay Slip (PDF) — Instant generation of signed settlement certificates (e-Parcha).
  6. Point 32: Multi-Party Digital Signatures — Validation blocks for Farmer thumbprint, Operator seal, and Mandi Secretary approval.
  7. Point 33: Split-Payment Capability — Multi-account payment disbursement for joint-ownership land holdings.
  8. Point 34: Immediate Cash-Advance Bridge — Tracking and reconciliation module for authorized short-term emergency cash advances.
  9. Point 35: Bank Account Verification (Penny Drop) — Real-time API check matching bank account names against land revenue records.
  10. Point 36: GST & Commercial Trader Invoicing — Automated commercial invoicing for private millers buying outside the state MSP pool.

Section D: Voice AI & Conversational Intelligence (Points 37–44)

  1. Point 37: Spoken Natural Language Booking — Hands-free voice booking enabling farmers to speak crop quantities aloud.
  2. Point 38: Multi-Dialect Accent Normalization — Speech engine tuned for rural inflections across Bengali, Hindi, and local dialects.
  3. Point 39: Spoken Token Status Inquiries — Voice query feature letting farmers ask for their queue position and receive spoken answers.
  4. Point 40: Voice-Activated Transit Delay Trigger — Spoken command reporting road delays to trigger the 45-minute standby window.
  5. Point 41: Audio Price & Moisture Quotation — Spoken readouts of declared MSPs, moisture limits, and permissible refractions.
  6. Point 42: Automated Ambient Noise Reduction — Microphone noise filtering to eliminate tractor engine rumble and market chatter.
  7. Point 43: Localized Speech Synthesis Persona — Reassuring regional voice profiles for rural farmer interactions.
  8. Point 44: Spoken Dispute Dictation — Voice-to-text recording allowing farmers to state disputes directly into the arbitration log.

Section E: Distributed Infrastructure, Algorithms & Security (Points 45–52)

  1. Point 45: Shortest-Job-First (SJF) Optimization Engine — Scheduling algorithm balancing FIFO order with load sizes to minimize yard wait times.
  2. Point 46: WebSocket Connection Resiliency Hub — Auto-reconnecting socket layer with exponential backoff and heartbeat pings.
  3. Point 47: Redis In-Memory Queue State — Fast in-memory state store providing sub-10 ms latency updates.
  4. Point 48: Distributed Relational Sync Engine — Dual-persistence layer ensuring operational data is backed up to relational storage.
  5. Point 49: Progressive Web App (PWA) Offline Service Worker — Full client caching allowing offline app access in cellular dead zones.
  6. Point 50: Anti-Bot Rate Limiting & CAPTCHA Shield — Token-bucket algorithm blocking automated script attacks during peak booking hours.
  7. Point 51: Edge-Network Fallback Node — Local Raspberry Pi micro-server deployment ensuring full mandi operation during ISP outages.
  8. Point 52: Universal REST & GraphQL Public API — Secure, tokenized API endpoints for integration with state e-Paddy and national e-NAM servers.

5. Strategic Phased Implementation Roadmap

Phase 1: Dual-Portal Core & Live Sync — Separate Citizen Entry vs Operator Desk, Mobile OTP / Krishak Bandhu login, and WebSocket updates.

Phase 2: Voice AI & Rural Illiteracy Inclusion — Conversational Voice Assistant (Bengali, Hindi, English), audio readouts, and visual iconography.

Phase 3: Weighbridge IoT & Assaying — Serial link to scale indicators, digital moisture meter integration, and automated net weight calculations.

Phase 4: Financial Settlement & Auditing — MSP calculation engine, Direct Benefit Transfer (DBT) hooks, and tamper-evident PDF pay slips.
