# KisanQueue: Smart Last-Mile APMC Procurement System

KisanQueue transforms unpredictable physical lines at agricultural procurement centres into an intelligent, data-driven flow with dynamic wait times, multi-counter dispatching, and automated Direct Benefit Transfer (DBT) records.

---

## 🚀 Getting Started Locally

### 1. Backend Setup

Make sure you have Python 3.9+ installed.

```bash
# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate

# Install dependencies
pip install -r backend/requirements.txt

# Run the server
python backend/run.py
